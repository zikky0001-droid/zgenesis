THE GENESIS API

A free, public API for searching the catalogue and resolving video stream and download links. No API key, subscription or payment card required.

Overview

Base URL

All JSON responses are formatted with two-space indentation. All endpoints use HTTPS and return JSON unless the download endpoint is called with redirect=true. The versioned API and its playground share the same per-IP limits. Existing website endpoints outside /api/v1/* are not rate-limited.

Quick example

GET /api/v1/search?q=one%20piece
Only use the API with video pages and content you are authorized to access. The API resolves links from the configured supported source domains; it is not a general-purpose URL fetcher.

Rate limits

Limits are applied per visitor IP address to the versioned /api/v1/* endpoints only. Website endpoints such as /api/home and /api/search are not included.

40 requestsPer minute · per IP
2,500 requestsPer hour · per IP

When a limit is exceeded, the API responds with HTTP 429 and a Retry-After header. Rate-limit headers report remaining requests and reset times. Successful checks return X-RateLimit-Status: active and X-RateLimit-Backend: upstash-redis. If Redis is unavailable, the API fails open and continues serving requests; the response reports X-RateLimit-Status: unavailable and enforcement is temporarily unavailable until Redis recovers. All JSON responses use two-space pretty formatting.

1. Search videos

GET/api/v1/search?q={query}
Search the configured catalogue source. Required: q (2–120 characters). Returns the scraped video results and source metadata.
curl "https://zgenesis.vercel.app/api/v1/search?q=one%20piece"

2. Get video details

GET/api/v1/video?url={videoPageUrl}
Resolve a supported video page and return its metadata, stream URL, download URL and related information. The URL must belong to one of the configured supported domains.
curl "https://zgenesis.vercel.app/api/v1/video?url=https%3A%2F%2Fwww.ccxx.com%2Fvideo-EXAMPLE"

3. Get stream link

GET/api/v1/stream?url={videoPageUrl}
Returns a direct upstream stream URL in JSON. When the signed URL exposes an expiry timestamp, the API returns it as an ISO 8601 expiresAt value; otherwise it returns null.
curl "https://zgenesis.vercel.app/api/v1/stream?url=ENCODED_VIDEO_PAGE_URL"

4. Get or open download link

GET/api/v1/download?url={videoPageUrl}
Returns a JSON download URL by default. Add redirect=true to redirect the browser to the upstream download URL, allowing the source server to handle the actual file transfer.
# JSON response curl "https://zgenesis.vercel.app/api/v1/download?url=ENCODED_VIDEO_PAGE_URL" # Browser redirect to the upstream file https://zgenesis.vercel.app/api/v1/download?url=ENCODED_VIDEO_PAGE_URL&redirect=true

The Genesis server resolves the link; it does not proxy or store the video file for this v1 endpoint.

Errors and response codes

400 invalid/missing input · 404 video or stream not found · 429 rate limit exceeded · 504 request deadline exceeded · 500/502 upstream or server failure.
